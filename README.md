## Homelab

My home network runs on a self-built server stack — not just for fun, but to actually understand the infrastructure that production systems are built on.

- **Hypervisor:** Proxmox VE — running multiple VMs and LXC containers
- **Networking:** OPNsense VM handling routing, firewall rules, and VLANs
- **Self-hosted services:** Various apps managed and exposed behind a reverse proxy
- **Goal:** Understand the full stack — from the metal to the application layer
